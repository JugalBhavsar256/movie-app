Movie App project by Jugal Bhavsar

A React-based movie website that allows users to browse trending movies, search for specific movies, find movies by genre, save their favourite movies, and learn
more about the movie.

Technologies Used
React.js
JavaScript
CSS
React Router
Movie Database API (TMDB)

Features
Browse Movies: View a collection of movies on the homepage.
Search Movies: Search for movies by title.
Favourites: Add movies to your favourites and view them on a separate page.
Browse by Genre: Filter movies based on different genres.
Movie Details: View information about individual movies.
